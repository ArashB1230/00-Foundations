# SQL Analytics

This project introduces relational analytics with SQLite. It focuses on how to structure tables, query the data, and compute useful summaries with SQL.

## Goal

The goal is to learn how to use SQL for analysis rather than only storing data. This includes filtering, grouping, aggregation, and looking at patterns in tabular data.

## What you will practice

- designing a minimal relational schema,
- writing SQL queries for analysis,
- using aggregate functions like counts and sums,
- grouping and summarizing data,
- inspecting results that answer business or data questions.

## Why this matters

Most data work involves tabular data at some point, and SQL remains the most direct language for exploring and summarizing it. Being comfortable with SQL is essential for analytics, ETL, and ML data preparation.

## Example activities

You may work with:
- customer data,
- product data,
- aggregated metrics,
- grouped summaries and comparisons,
- basic analytical questions that can be answered in a database.
